# Local Repo Inspector - Synthetic Demo

**Demo output only. No executable, source-code package, checkout, or public trial is provided by this repository.**

Local Repo Inspector is a research-stage Python CLI that can summarize the disk
footprint of a local project using filesystem metadata **without uploading
source-code contents**.

It reports counts and byte sizes for files and directories, file-extension
distributions, largest files and folder hotspots. It can flag files exceeding
a chosen size threshold. It excludes typical generated/cache directories.

This is not a Git performance repair, code architecture visualizer, security
scanner, secret detector, or automatic cleanup tool.

## Demonstration generated by the real metadata engine

The following values come from **fabricated project files** in an ephemeral
local fixture. They are not from a customer repository.

| Synthetic measure | Demonstrated result |
| --- | ---: |
| Included files | 7 |
| Scanned directories | 6 |
| Included bytes | 132,725 |
| Excluded generated/cache directories | 2 |
| File-size limit | 65,536 bytes |
| Oversized files detected | 1 |

The example includes an intentionally oversize 123,456-byte dummy binary.
The report's *Policy: FAIL* is an expected demonstration of the alert,
not a failed software test.

### Files in this public-demo candidate

- `report.txt` - example human-readable metadata output.
- `report.json` - example structured metadata output.
- `fixture_spec.json` - fictional file tree specification and sizes.
- `demo_manifest.json` - SHA-256 digests and byte sizes for the three
  generated example reports.

Only a self-contained synthetic example is shown. No program capable of
inspecting your filesystem is distributed here.
